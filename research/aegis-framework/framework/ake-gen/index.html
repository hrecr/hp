FRAMEWORK MODULE · WORKFLOW STEP 04

IoT-PQ-AKEgen

A generalized representation for proof-compatible protocol modeling. It is intended for evaluating existing protocols and guiding future protocol instances while remaining primitive-, flow-, and transport-independent.

PARTIAL COMPATIBILITY

Gaps become obligations, not invented behavior.

A protocol may be partially representable. Missing credential identifiers, algorithm bindings, state timing, or failure behavior remain explicit adapter gaps and later proof obligations.

Conformance is not proof

Framework conformance does not establish a complete cryptographic theorem.

Metadata is not authenticated

Canonical framework metadata is not automatically protocol-authenticated.

Identifiers may be external

A canonical session identifier does not imply the wire protocol computes it.

No full UC claim

The framework does not claim full universal composability.
