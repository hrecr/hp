FRAMEWORK · FOUR MODULES

The AEGIS Framework

The framework separates protocol inspection, generalized representation, structural compatibility, and formal security definitions. This prevents a single vague “secure” label from hiding different models or assumptions.

COMPARISON

AKEmin and AKEgen comparison
DimensionAKEminAKEgen
Main purposeInspect existing protocolsBuild a proof-oriented representation
InputNormalized concrete protocolReviewed AKEmin mapping

AEGIS does not claim full universal composability. The framework is positioned as a lighter, protocol-independent layer between isolated protocol-specific games and full composable treatments.
