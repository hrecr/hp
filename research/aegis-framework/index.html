Unifying Security Analyses for Post-Quantum IoT Protocols

A proposal defining a minimal, comprehensive model (IoT-PQ-AKE_min) to standardize the evaluation of modern post-quantum authentication and key-establishment protocols.

Explore the Analysis ↓

The Fragmentation Problem

Post-quantum IoT protocols (like PQ-EDHOC, AuthKEM-EDHOC, PQ-Lattice) are emerging rapidly. However, their security analyses are wildly inconsistent, making it impossible to directly compare their security guarantees.

Current Proof Methodologies

Researchers currently utilize a fractured landscape of formal and informal verification tools. Because models like ProVerif handle state differently than BAN logic or RoR proofs, a protocol "proven secure" in one paper may fail under the threat model of another.

  • • RoR (Real-or-Random) proofs
  • • BAN Logic
  • • ProVerif / AVISPA
  • • Informal heuristic arguments

The Analysis Gap

Standard protocol analyses often miss critical vulnerabilities specific to constrained IoT environments in a post-quantum world. We must bridge the gap between theoretical security and physical reality.

Crucial Missing Elements

State Leakage
IoT devices are easily captured. Partial state leakage resilience is rarely formalized.
Energy Exhaustion
Adversaries forcing expensive PQ operations to drain constrained batteries.
Desynchronization
Attacks targeting stateful hash-based signatures or counters causing connection denial.
Downgrade Attacks
Forcing protocols back to classical algorithms during the PQ transition phase.

The Proposed Framework: IoT-PQ-AKE_min

A unified model offering a common language to review recent post-quantum IoT authentication and key-establishment protocols. Explore the formalized queries and goals below.

Explicit Contributions

➀

Define Minimal Model

We define a minimal post-quantum AKE model tailored for IoT, establishing a rigorous baseline.

➁

Formalize Queries

Rigorous definitions for Send, Execute, Reveal, Corrupt, EphemeralReveal, StateReveal, and Test queries.

➂

Define Goals

Formalizing AKE secrecy, KCI/UKS resistance, state-leakage, desynchronization, and energy-exhaustion resilience.

➃

Map Existing Methods

We translate RoR, BAN, ProVerif, and AVISPA into our model, identifying exact proof coverage and blind spots.

➄

Protocol Evaluation

Applying the unified model to evaluate and compare recent protocols like PQ-EDHOC and Kyber-based IoT AKE.

➅

Implementation Data

Optional: Providing realistic performance comparisons and implementation experiments on constrained networks.
